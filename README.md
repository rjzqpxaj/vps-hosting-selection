## 建站 VPS 到底该看哪几个指标

内存和流量是建站场景的前两名。WordPress 加上数据库，1GB 内存跑得动但偏紧，2GB 会从容很多；流量则决定你的站能扛多少访问——一台配 1.5TB 月流量的机器，日均承载几百到上千 PV 的图文站点没有压力，配图多或被搜索引擎放量后再往上加。
